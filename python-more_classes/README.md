# Python - More Classes and Objects

This project is part of the Holberton School Higher Level Programming curriculum.

## Description

This directory contains exercises focused on understanding classes and objects in Python.  
The goal is to strengthen knowledge of:

- Object-Oriented Programming (OOP)
- Class definitions
- Attributes and methods
- Encapsulation principles
- Python data model

## Task 0: Simple Rectangle

The first task requires creating an empty class `Rectangle` without importing any modules.

### File:
- `0-rectangle.py`

This class serves as the foundation for more advanced object-oriented implementations in upcoming tasks.

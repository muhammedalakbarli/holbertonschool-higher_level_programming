# Python - Inheritance

This project covers Object-Oriented Programming (OOP) concepts in Python, focusing on inheritance.

## Concepts covered

- Classes and objects
- Attributes and methods
- Instance vs class attributes
- Inheritance
- Built-in functions like dir()
- Special methods (__init__, __str__, __repr__)

All files are written for Python 3.8 and follow pycodestyle (2.7.*).
